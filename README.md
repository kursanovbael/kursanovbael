## 🔥 Featured Projects

### **Phys.io** — Agentic Radiative-Cooling Discovery Lab
🏆 *Hack-Nation Hackathon, Oct 2026 | 1st Place*

Multi-agent AI lab that designs passive daytime radiative-cooling coatings by combining Omnigent agents with a physics simulator.

**My role**: Full-stack platform (backend API, interactive designer, proof analysis)
- Built **transfer-matrix optics REST API** (FastAPI) + simulator integration  
- Designed **interactive coating designer** with live cooling power, spectra, 3D photon visualization (React/Three.js)
- Led **proof analysis**: median evals-to-target, success rates, 95% bootstrap CI across 6 search methods
- **Result**: Best cheap 4-layer design **56.7 W/m²** vs Stanford's 7-layer **11.8 W/m²** (same simulator)

**Stack**: FastAPI · React · TypeScript · Three.js · Transfer-Matrix Optics · NumPy

### **FireWatch** — Human-Supervised Wildfire Detection
🥈 *Stanford Hackathon, Sep 2026 | 2nd Place*

Real-time wildfire detection fusing 1,200+ camera feeds, NASA FIRMS satellite thermal data, and weather evidence.

- **Federated Learning**: Flower framework keeps station data local, shares learned fusion thresholds  
- **Vision**: YOLOv8 fire detection + Qwen multi-modal reasoning (Nebius)
- **Backend**: FastAPI event pipeline
- **Frontend**: React
- **Impact**: False alarms **33.6% → 8.1%**, missed fires **13.9% → 3.2%** on 117 simulated stations

**Stack**: Python · FastAPI · YOLOv8 · Qwen · Flower · React
